  - **GOTCHA (real lesson, cost ~539k gas on a throwaway deploy)**: appended the ERC-8021 attribution suffix to the CREATE2 factory calldata by mistake. The Arachnid deterministic-deployment proxy treats *everything* after the first 32 bytes (salt) as literal init code to execute via `CREATE2` — it does not parse it as "function calldata with an ignorable trailing suffix" the way a normal contract call does.
